# 🔍 AI Mystery Room

A full-stack AI-powered mystery investigation game where players interrogate suspects, gather clues, and make accusations to solve cases generated by Google Gemini.

## 📦 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite |
| Backend | Node.js + Express 5 |
| Database | MongoDB via Mongoose (in-memory fallback for local dev) |
| AI | Google Gemini via `@google/genai` |
| Validation | Zod |
| Deployment | Render (Blueprint via `render.yaml`) |

---

## 🚀 Local Setup

### Prerequisites

- **Node.js** `>= 20.19.0` — [Download](https://nodejs.org)
- **npm** (comes with Node.js)
- **MongoDB** running locally (optional — the app falls back to in-memory storage)
- **Gemini API key** (optional — the app uses a local deterministic case generator if not set)

---

### 1. Clone the Repository

```bash
git clone https://github.com/bichu0017/AI_investigation_room.git
cd AI_investigation_room
```

---

### 2. Set Up the Backend

```bash
cd server
npm install
cp .env.example .env
```

Edit `.env` and fill in your values:

```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/ai_mystery_room   # Optional: leave blank for in-memory fallback
GEMINI_API_KEY=                                          # Optional: leave blank to use local case generator
GEMINI_MODEL=gemini-2.5-flash
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

Start the dev server:

```bash
npm run dev
```

The API will be available at `http://localhost:5000`.  
Health check: `http://localhost:5000/api/health`

---

### 3. Set Up the Frontend

Open a new terminal:

```bash
cd client
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`.

---

### 4. Run Tests

```bash
cd server
npm test
```

Tests use Node's built-in test runner (`node --test`) with `supertest`.

## 🎮 How to Play

1. **Create a case** — Enter a mystery premise and choose a difficulty level.
2. **Investigate** — Ask questions, examine suspects, and uncover clues.
3. **Request hints** — You have a limited number of hints available.
4. **Make an accusation** — When ready, accuse a suspect.
5. **See your verdict** — Your score and the full solution are revealed only after your accusation.

> **Note:** The server intentionally hides the solution until the accusation is made — no peeking via the API!

## 🌐 Deploy to Render

This project is pre-configured for one-click deployment via [`render.yaml`](./render.yaml). The Express server serves both the API and the built React frontend as a single Render web service.

### Step 1 — Push to GitHub

Make sure your latest changes (including `render.yaml`) are pushed to the branch you want to deploy.

### Step 2 — Create a MongoDB Atlas Database

1. Sign in to [MongoDB Atlas](https://www.mongodb.com/atlas) and create a **free cluster**.
2. Create a **database user** and save the credentials.
3. Under **Network Access**, add `0.0.0.0/0` to allow connections from Render.
4. Click **Connect → Drivers**, copy the Node.js connection string, and replace `<password>`.
5. Append a database name to the URI, e.g.:
   ```
   mongodb+srv://<user>:<password>@<cluster-host>/ai_mystery_room?retryWrites=true&w=majority
   ```

### Step 3 — Create the Render Service

1. Sign in to [Render](https://render.com) → **New → Blueprint**.
2. Connect your GitHub repository and select the branch with `render.yaml`.
3. When prompted, set the environment variable `MONGODB_URI` to your Atlas connection string.
4. Click **Apply** and wait for the build to complete.

### Step 4 — (Optional) Enable Gemini AI Cases

1. Get a free API key from [Google AI Studio](https://aistudio.google.com/apikey).
2. In Render → **Environment**, add `GEMINI_API_KEY` and save.
3. Render will automatically redeploy with AI-generated cases enabled.

> ⚠️ **Never commit your API key or database password to Git.**

### Step 5 — Verify the Deployment

- Open the Render service URL — the game should load.
- Visit `<your-render-url>/api/health` — you should see `{"ok": true}`.

## 🛠 Troubleshooting

| Problem | Solution |
|---------|----------|
| Build fails on Render | Check build logs; ensure Node.js `>= 20.19` is used |
| App can't connect to MongoDB | Verify `MONGODB_URI` is set and Atlas Network Access allows `0.0.0.0/0` |
| No AI cases being generated | Confirm `GEMINI_API_KEY` is set in Render's Environment settings |
| Slow first load on Render | Render free tier spins down after inactivity; first request may take ~30s |
| CORS errors locally | Ensure `CLIENT_URL=http://localhost:5173` is set in `server/.env` |
